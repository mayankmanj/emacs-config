* Overview

Migrate the Emacs config from [[https://github.com/radian-software/straight.el][straight.el]] to [[https://github.com/progfolio/elpaca][elpaca]].

** Key differences
| Concern                 | straight.el                                    | elpaca                                              |
|-------------------------+------------------------------------------------+-----------------------------------------------------|
| Default for use-package | ~(setq straight-use-package-by-default t)~     | ~(elpaca-use-package-mode)~                         |
| Built-in packages       | ~:straight (:type built-in)~                   | ~:ensure nil~                                       |
| Custom git recipe       | ~:straight (:type git :host github :repo ...)~ | ~:ensure (:host github :repo ...)~                  |
| GitHub SSH recipe       | ~:straight (:type git :host nil :repo "git@…")~| ~:ensure (:url "git@…" :branch "…")~                |
| Host usernames          | ~straight-host-usernames~                      | Not needed; use full URLs or ~:host~/~:repo~        |
| Init ordering           | Synchronous                                    | Async by default; use ~elpaca-wait~ to block        |
| package.el              | Coexists                                       | Disabled via ~package-enable-at-startup nil~        |

* Notes

- Elpaca stores built packages in =~/.config/emacs/elpaca/builds/= and source
  repos in =~/.config/emacs/elpaca/sources/=.
- ~use-package-always-ensure t~ in =early-init.el= is compatible with elpaca
  (~elpaca-use-package-mode~ makes ~:ensure t~ use elpaca). Kept as-is.
- For built-in or local packages use ~:ensure nil~.
- Recipe keyword reference: https://github.com/progfolio/elpaca#recipes
